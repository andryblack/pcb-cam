# Sample fabrication data

Synthetic board files used by **File → Load Demo Project** and by
`cargo run -p pbc-cam -- --sample`.

- `demo-F_Cu.gbr` — top copper traces, pads and a filled copper region
- `demo-Edge_Cuts.gbr` — rounded board outline with G03 arcs
- `demo.drl` — plated through holes, vias and mounting holes
- `demo-Silkscreen.gbr` — legend frame and PBC lettering for the engraving task

The files are original test data for PBC-CAM and contain no third-party
design data.
